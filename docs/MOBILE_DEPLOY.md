# BossHunter 手机端部署与使用指南

本文档介绍如何将 **BossHunter** 部署为手机端可用，实现在沙发上、床上或出门时通过手机随时查看岗位、审核 AI 评分、一键投递以及接收 HR 消息。

---

## 架构原理说明

- **电脑端（主控与执行引擎）**：
  - 运行桌面版 Google Chrome（开启远程调试端口 9222），维持 BOSS 直聘、智联招聘、51job 的真实登录态与滑块/反爬风控；
  - 运行 BossHunter 后端服务，监听 `0.0.0.0:8686`。
- **手机端（移动工作台与审批触控端）**：
  - 手机连接同一局域网（或通过远程组网）直接扫码打开移动端自适应控制台；
  - 底部大拇指 TabBar 轻松切换：工作台、岗位池、监测执行、配置设置；
  - 支持添加到手机主屏幕（PWA），全屏无地址栏像原生 App 一样流畅使用。

---

## 快速上手步骤

### 第一步：启动服务

在项目根目录下，直接双击运行：
👉 `start-mobile.bat`

或者在命令行终端中执行：
```bash
bosshunter web --host 0.0.0.0 --port 8686
```

此时终端会自动输出电脑访问地址、**手机端访问地址**以及**手机扫码直达二维码**：
```text
============================================================
 🚀 BossHunter 控制台已启动
============================================================
 💻 电脑本机访问: http://127.0.0.1:8686
 📱 手机端访问:   http://10.3.182.148:8686

 💡 手机端连接说明:
   1. 手机需与电脑连接同一 Wi-Fi 局域网
   2. 手机打开相机或微信，直接扫描下方二维码访问
   3. 可在手机浏览器菜单中选择「添加到主屏幕」，即可全屏秒开
```

### 第二步：手机连接与添加到桌面

1. 确保手机和电脑连在**同一个 Wi-Fi** 下；
2. 打开手机**微信**或**系统相机**，对准电脑终端屏幕上的二维码扫一扫；
3. 网页打开后：
   - **iPhone (Safari)**：点击底部的「分享」按钮 ➔ 选择「添加到主屏幕」；
   - **Android (Chrome / 浏览器)**：点击右上角菜单 ➔ 选择「安装应用」或「添加到桌面」；
4. 此时手机桌面上会出现 **BossHunter** 图标，点击即可像原生 App 一样全屏打开，随时随地审批岗位！

## 常见问题排查

### 1. 手机扫码后打不开网页？
- **原因**：Windows 防火墙拦截了局域网对 8686 端口的入站连接。
- **解决方法**：以**管理员身份**打开 PowerShell 或命令提示符，执行以下命令放行端口：
  ```cmd
  netsh advfirewall firewall add rule name="BossHunter Mobile" dir=in action=allow protocol=TCP localport=8686
  ```
- **检查 Wi-Fi 是否为同一网络**：确认手机 Wi-Fi 与电脑连接的是同一个路由器（不要一个是手机热点、一个是路由器，或者处于路由器访客隔离网络）。

## 进阶：出门在外（公网/远程）手机访问

如果想在外出、上班通勤或不在同一局域网时通过手机访问 BossHunter：

### 方案一：使用 Tailscale（推荐，极简安全且完全免费）
1. 电脑与手机分别安装 [Tailscale](https://tailscale.com/) 并登录同一账号；
2. 在电脑 Tailscale 中查看分配的 100.x.x.x 虚拟内网 IP（例如 `100.80.20.10`）；
3. 无论手机身处何地（包括使用 4G/5G 移动流量），在手机浏览器直接输入 `http://100.80.20.10:8686` 即可远程访问！

### 方案二：使用 Cloudflare Tunnel（免公网IP、支持自定义域名）
1. 下载 `cloudflared` 并在电脑端运行：
   ```bash
   cloudflared tunnel --url http://127.0.0.1:8686
   ```
2. Cloudflare 会生成一个临时的公网 HTTPS 链接（如 `https://xxx.trycloudflare.com`）；
3. 手机直接打开该 HTTPS 链接即可，无需任何客户端。
